# Kelas Giri — Lab Imersif Psikologi Belajar PAI (VR · AR · GenAI)

Media pembelajaran mata kuliah **Psikologi Belajar PAI**. Mahasiswa calon guru masuk ke kelas madrasah 3D, mengamati enam peserta didik virtual, mengumpulkan data, mewawancarai siswa (diperankan GenAI), mendiagnosis dengan teori psikologi belajar, lalu merancang intervensi yang ramah psikologis bersama mentor AI **Ustadzah Rose**.

## Cara menerbitkan di GitHub Pages (gratis)
1. Masuk ke https://github.com, klik **+ → New repository**. Isi Repository name dengan `kelas-giri`, pilih **Public**, lalu klik **Create repository**.
2. Klik **uploading an existing file**, seret `index.html` dan `README.md`, lalu klik **Commit changes**.
3. Buka **Settings → Pages**. Pada **Branch**, pilih `main` dan `/ (root)`, lalu klik **Save**.
4. Tunggu 1–3 menit. Link publik: `https://NAMA-AKUN.github.io/kelas-giri/`

## Fitur
- VR: kelas 3D WebXR (A-Frame 1.6); tombol kacamata VR muncul di perangkat yang mendukung.
- AR: model memori Atkinson–Shiffrin, belajar observasional Bandura, dan regulasi diri Zimmerman lewat kamera, foto meja, atau WebXR.
- GenAI: Puter.js (gratis, tanpa API key; pengguna masuk akun Puter sekali). Bila tidak tersedia, aplikasi berjalan dalam mode luring.

Profil siswa adalah indikasi pedagogis untuk latihan, bukan diagnosis klinis.
